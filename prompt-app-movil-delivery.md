# 📱 PROMPT COMPLETO: APP MÓVIL HÍBRIDA DE DELIVERY "QUIÚBOLE!"

## 🎯 DESCRIPCIÓN GENERAL DEL PROYECTO

Crea una aplicación móvil híbrida (iOS y Android) de alta calidad para una plataforma de delivery multi-negocio llamada **"Quiúbole!"**. La app debe ser comparable en funcionalidad y diseño a Rappi, Uber Eats o DiDi Food, con interfaces modernas, fluidas y profesionales.

---

## 👥 TIPOS DE USUARIOS Y SUS APLICACIONES

El sistema necesita **4 aplicaciones móviles diferentes:**

### 1. APP DE CLIENTES (Consumidores)
- Explorar restaurantes y negocios
- Hacer pedidos
- Rastrear entregas en tiempo real
- Gestionar pagos y métodos de pago
- Sistema de reseñas y calificaciones
- Historial de pedidos
- Favoritos y reordenar

### 2. APP DE REPARTIDORES (Conductores/Delivery)
- Recibir notificaciones de pedidos disponibles
- Aceptar/rechazar pedidos
- Navegación GPS integrada
- Estado en línea/fuera de línea
- Historial de entregas y ganancias
- Chat con cliente y restaurante

### 3. APP DE RESTAURANTES/NEGOCIOS (Socios Comerciales)
- Panel para gestionar menú y productos
- Recibir y aceptar pedidos
- Gestionar tiempos de preparación
- Notificar cuando el pedido está listo
- Ver estadísticas de ventas
- Chat con repartidor

### 4. APP DE ADMINISTRADORES
- Dashboard completo
- Gestión de usuarios (clientes, repartidores, negocios)
- Monitoreo de pedidos en tiempo real
- Reportes y analytics
- Gestión de comisiones y pagos
- Soporte y resolución de problemas

## 🛠️ STACK TECNOLÓGICO RECOMENDADO

### Framework Principal:
**OPCIÓN A (Recomendada):**
```
- Framework: React Native (con Expo para desarrollo más rápido)
- Lenguaje: TypeScript (para código más seguro y mantenible)
- Navegación: React Navigation 6
- Estado Global: Redux Toolkit o Zustand
- UI Components: React Native Paper o NativeBase
- Animaciones: React Native Reanimated 2 + Moti
```

**OPCIÓN B (Alternativa):**
```
- Framework: Flutter
- Lenguaje: Dart
- Estado: Riverpod o Bloc
- UI: Material Design 3 + Custom Widgets
- Animaciones: Flutter Animations API
```

### Backend y Base de Datos:
```
- Backend: Node.js + Express.js o Nest.js
- Base de datos principal: PostgreSQL
- Base de datos en tiempo real: Firebase Realtime Database o Supabase
- ORM: Prisma o TypeORM
- API: RESTful + WebSockets para tiempo real
```

### Servicios de Terceros:
```
- Mapas y Geolocalización:
  * Google Maps API (mostrar mapas)
  * Google Directions API (rutas)
  * Google Places API (autocompletar direcciones)
  * Geolocation API nativo

- Pagos:
  * Stripe (tarjetas internacionales)
  * Conekta/OpenPay (México)
  * PayPal
  * Mercado Pago (Latinoamérica)

- Notificaciones Push:
  * Firebase Cloud Messaging (FCM)
  * OneSignal (alternativa)

- Almacenamiento de Imágenes:
  * Cloudinary (con optimización automática)
  * AWS S3 + CloudFront

- Autenticación:
  * Firebase Authentication
  * Auth0
  * JWT custom

- SMS/WhatsApp:
  * Twilio (verificación, notificaciones)
  * WhatsApp Business API

- Analytics:
  * Google Analytics
  * Mixpanel
  * Amplitude
```

## 🔧 REQUERIMIENTOS TÉCNICOS ESPECÍFICOS

### Performance:
- **Tiempo de carga inicial:** < 3 segundos
- **FPS mínimo:** 60fps en animaciones
- **Tamaño de app:** < 50MB (sin imágenes cacheadas)
- **Uso de memoria:** < 200MB en uso normal
- **Compatibilidad:**
  - iOS: 13.0+
  - Android: API 21+ (Android 5.0+)

### Offline Capabilities:
- Caché de imágenes de restaurantes visitados
- Historial de pedidos disponible offline
- Direcciones guardadas accesibles sin conexión
- Sincronización automática al recuperar conexión

### Seguridad:
- Encriptación de datos sensibles (SSL/TLS)
- Tokens JWT con refresh
- Nunca guardar números de tarjeta (usar tokens de Stripe)
- Validación de inputs en cliente y servidor
- Protección contra XSS y SQL injection
- Rate limiting en APIs

### Accesibilidad:
- Soporte para lectores de pantalla
- Tamaños de texto ajustables
- Alto contraste disponible
- Labels descriptivos en todos los elementos

### Testing:
- Unit tests (Jest)
- Integration tests
- E2E tests (Detox para React Native, o Maestro)
- Test de performance
